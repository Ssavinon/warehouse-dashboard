SO / TR Rollover

Rollover candidates are SO/TR requests without FirstPackedOn. Weekly OpsActivityLog can identify packing activity for those requests, but their unfilled lines and backorder reasons must be verified. Backlog from OpsActivityLog remains a separate measure.

About this dashboard

Historical imports stay in the same browser profile only. Export a data backup regularly to OneDrive; saving this HTML file alone does not back up the imported orders. Use the same browser/device for daily imports. This is a working browser dashboard, not a hosted company service. For shared online access, secure authentication, automatic backups, and multi-user history, deploy a server-backed version approved by your IT department.

OpsActivityLog — Weekly Validation & Picker Production

Optional weekly upload only. Keep your daily SO/TR uploads at the top of the page. The Activity Log is for validating weekly work, investigating backlog, and reviewing picker production. Backlog totals will require confirmation of the relevant Activity Log columns.

Import weekly activity

Counts identified packing activity by packed date (or packing-event date), not RequestedOn. Picker packed-order totals and QC Done totals come only from the weekly OpsActivityLog, not from Requested SO/TR. QC activities are counted separately from packing activities. Packer productivity requires an identifiable order and packing activity; rows without a picker display as Unassigned. The report structure will be verified after your first real upload.

After importing, choose Weekly Performance → Pickers or Packers to see orders and lines.
